Diagnostico Estrategico — Alumni by Better

Cruzamento: 570 vendas (CRM) + Dados de canal + Taxonomia de tags + Ata de reuniao de heads

O que sao as tags? Cada lead no CRM recebe multiplas tags ao longo da jornada. Um unico lead pode ter 5, 10, ate 20+ tags. Analisando as tags dos 570 leads que converteram, podemos entender: por quais canais passaram, quantas vezes foram tocados por remarketing, se sao ex-alunos, se vieram de parcerias, etc.

Problemas Criticos na Taxonomia de Tags

Problemas Encontrados

Tags duplicadas com nomes diferentes
"leads fer" vs "LEADS FERR" vs "Base Fer" vs "Lista Fernanda Soares" — 4 tags para o mesmo conceito
Sem padrao de nomenclatura
Mix de MAIUSCULAS, minusculas, snake_case, espacos, emojis (📆👥). Impossibilita automacao
Tags de remarketing como "lixeira"
30+ tags de remarketing acumulando. Lead com 15 tags de rmkt perde legibilidade. Criar campo separado
Status misturado com origem
"CANCELADO" e status mas tambem indica ex-aluno que reativou. Criar campo de historico separado
Tags operacionais poluindo analytics
"Celular Fe", "BUG", "PARAR ENVIO MSG" sao operacionais, nao deviam impactar analise de marketing

Recomendacoes de Padronizacao

Criar campos dedicados no CRM
Canal (dropdown), Campanha (dropdown), Vendedor (lookup), Status (workflow). Tags somente para segmentacao
Unificar nomenclatura
Padrao: snake_case_minusculo. Ex: "parceria_daycoval", "campanha_black_friday_2025", "rmkt_jan_2026"
Limpar tags de remarketing
Mover historico de disparos para campo "Historico de Comunicacao". Tag = segmento atual, nao historico
Implementar tag de fonte primaria
1 tag unica de fonte: "fonte:google_ads", "fonte:indicacao", "fonte:parceria_daycoval". Sem ambiguidade
Auditar e limpar base
Remover tags obsoletas (MSI_2022, SETUP_2023). Mergear duplicatas. Documentar taxonomia oficial

Insights Chave das Tags

43% tocados por remarketing

245 dos 570 leads que converteram tinham tags de remarketing. Isso significa que quase metade das vendas foi influenciada por remarketing. O remarketing NAO e custo — e investimento essencial no funil.

25% vieram de bases antigas

143 leads eram de listas MSI, ex-alunos, ou bases historicas. A reativacao de base e um canal significativo. A reuniao mencionou esse potencial — os dados confirmam.

13% por indicacao (custo zero)

74 leads vieram de "Indicacao Alumni". Sem custo de aquisicao. Um programa formal de Member Get Member poderia dobrar esse numero. A Ata menciona foco em retenção — aluno satisfeito indica.
